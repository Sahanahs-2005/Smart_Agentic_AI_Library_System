# Smart Agentic AI Library System

## Project Overview

The Smart Agentic AI Library System is an AI-based project developed as part of the AICW — AI Careers for Women — skilling program. The project demonstrates how artificial intelligence can support library-related activities and provide an intelligent user experience.

## Program

This project was developed during the AICW program supported by Microsoft and SAP, in collaboration with the Ministry of Skill Development & Entrepreneurship and Edunet Foundation.
